# CYBORG — The Future of Humanity

A responsive cyberpunk-themed landing page Developed by **Manthan Sthul** using HTML, CSS and JavaScript.

## Run locally
1. Download and extract the project ZIP.
2. Open the `cyborg-landing-page` folder.
3. Open `index.html` in a browser.

No build tools or dependencies are required. Google Fonts are loaded online; the site layout and hero image are included locally.

## Project files
- `index.html` — page structure and content
- `style.css` — responsive styling and visual effects
- `script.js` — mobile navigation and small interactions
- `assets/cyborg-hero.png` — original generated hero artwork

## Before submitting
1. Create a GitHub repository named `cyborg-themed-landing-page`.
2. Upload all project files, keeping the `assets` folder.
3. Enable GitHub Pages in the repository settings (Deploy from branch → `main` → `/root`).
4. Open the published website and record a short screen demo showing the desktop/mobile layout and navigation.
5. Upload the recording to Google Drive and set General access to **Anyone with the link — Viewer**.
6. Submit the GitHub repository URL and the Google Drive recording URL in the task form.
